Сюда скрипт ml/train.py кладёт обученные модели:

  activity_model.tflite   — классификатор активности
  placement_model.tflite  — классификатор положения телефона (нужны свои данные)
  model_meta.json         — каналы, классы, статистики нормировки, точность

Пока этих файлов нет, приложение собирается и работает на эвристическом
классификаторе и честно сообщает об этом на экране «О модели».

Запуск обучения:
  pip install -r ml/requirements.txt
  python ml/train.py --source uci
